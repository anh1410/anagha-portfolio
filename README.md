# hi, i'm anagha 

**[live here →](https://anh1410.github.io/anagha-portfolio/)**

this is my portfolio. 

i'm a B.Tech CCE student at NMAM Institute of Technology, and somewhere along the way "let me learn to code" turned into freelancing full-stack builds, deploying school servers at 11pm, and writing a load balancer in C++ because apparently I needed to know what a WAF is at 2am. this site is basically a highlight reel of that chaos, dressed up in lavender and chrome so it doesn't look like one.

## what's actually here

- **StockOS** — an inventory + repair-ticket system I built (and still maintain) for a real client. 8 modules, a transaction ledger, and enough audit-trail enforcement to make sure nobody can quietly delete their mistakes.
- **SynapSet** — the project I'm proudest of. It reads syllabi, understands Bloom's taxonomy better than I did in school, and uses constraint optimization to assemble exam papers that are actually balanced. Built for a real school that was tired of manually writing question papers.
- **MiniADC** — a C++ load balancer / WAF because I wanted to know what happens under the hood of the infrastructure everyone takes for granted. Turns out: a lot of async I/O and yelling at segfaults.
- **voiceNova** — built this one for myself first. My brain doesn't do neat to-do lists, so I made an app that lets me just talk and figures out the tasks later.

## the site itself

- React + Vite, Tailwind v4, Framer Motion
- glassmorphic cards, a chrome border that shimmers if you stare at it long enough
- a cursor that follows you around like it has somewhere to be
- zero dark mode toggle because I designed this to be loud and bright on purpose, sorry not sorry

## running it locally

```bash
npm install
npm run dev
```

that's it. no ceremony.

## why this exists

mostly because recruiters were going to look at a resume PDF anyway, and I'd rather they land somewhere that feels like me — a little extra, a little glowy, held together by genuine effort instead of a template.
